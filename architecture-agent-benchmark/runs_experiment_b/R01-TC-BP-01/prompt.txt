We keep running into a situation that's costing users money: a strategy takes several losing trades in a
row on the same pair — clearly a sign that current conditions aren't working for it — but the bot just
keeps re-entering into the same pair anyway instead of taking a step back. Traders end up having to watch
the bot manually and pause it themselves after a bad streak, which defeats the point of automation.

Please add a safety mechanism that tracks losing trades in a row (not total profit, specifically a
consecutive-loss streak) and, once a configurable number of consecutive losses has happened for a given
pair, stops the bot from opening any new trades on that pair for a configurable cool-down period. We'd
also like an equivalent bot-wide version: if losses are piling up in a row across trading in general
(not tied to one specific pair), pause new entries everywhere for a while, not just on one pair.

Operators should be able to configure the loss-streak threshold and the cool-down duration per strategy,
alongside the other risk-management knobs they already set there. Once the cool-down period elapses, new
trades on the affected pair(s) should be allowed again automatically — no manual intervention needed. The
pause should be visible through whatever channel the bot already uses to let users know trading has been
automatically interrupted, consistent with how similar automatic pauses are already surfaced today.


This repository has Goga tooling and skills available (already connected) if you find them useful for this task.
