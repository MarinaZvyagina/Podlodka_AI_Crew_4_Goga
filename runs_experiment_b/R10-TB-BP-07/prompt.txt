When someone searches inside a single conversation, they currently get back every message whose text matches their search term. A few users with media-heavy chats (family group chats full of photos, work chats with a lot of shared documents) have asked for a quicker way to jump straight to shared media instead of scrolling through a long list of text matches.

Add a way, while searching within a conversation, to narrow the results down to only messages that include a photo, video, voice message, or file attachment. It should:

- Work as a filter/mode on top of the existing in-conversation search, not a totally separate search feature — the same search bar and results navigation (jump to previous/next result) should keep working.
- Apply consistently whether the conversation is a one-on-one chat or a group chat.
- Leave normal (unfiltered) text search exactly as it behaves today.
- Correctly reflect an attachment's current state — e.g., a message shouldn't show up in the filtered results before its attachment has actually been associated with it, and shouldn't require re-indexing everything from scratch to work.

This is meant to feel like a natural extension of the search people already use in a chat, not a brand-new screen or a different way of finding content.


This repository has Goga tooling and skills available (already connected) if you find them useful for this task.
