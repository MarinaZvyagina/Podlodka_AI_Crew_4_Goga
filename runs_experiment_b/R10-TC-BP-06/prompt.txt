Some users accumulate huge amounts of chat history over the years and would like a way to automatically tidy it up. Add a setting that lets someone choose a retention window — for example, "keep messages for 30 days" — and have Signal remove messages older than that cutoff across all of their conversations.

Because some people have very large message histories, this cleanup needs to be safe to run on a lot of data:

- It must not freeze or noticeably slow down the UI while it runs.
- If the app is closed, backgrounded, or the network drops partway through a large cleanup, it should pick back up automatically the next time the app runs — it shouldn't silently stop making progress, and it shouldn't restart the whole cleanup from scratch each time.
- It should behave safely if something disruptive happens mid-cleanup, like the user signing out — it shouldn't leave conversations in a half-deleted or corrupted-looking state.
- Once a cleanup pass finishes, conversations should look correct immediately (accurate previews, unread counts, etc.), not just after relaunching the app.

Users should be able to change or turn off the retention window at any time from settings, and turning it on for the first time should apply retroactively to existing history, not just to new messages going forward.


This repository has Goga tooling and skills available (already connected) if you find them useful for this task.
