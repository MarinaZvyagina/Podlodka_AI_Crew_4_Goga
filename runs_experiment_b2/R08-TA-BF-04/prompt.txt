## Ticket: Blocked contacts list is not sorted

**Reported by:** Support triage
**Component:** Privacy settings — Blocked contacts

### Description

Several users have reported that the "Blocked contacts" screen (Settings → Privacy → Blocked contacts) shows blocked people in an order that looks random and doesn't match how they blocked them. When someone has blocked more than a handful of contacts, it's hard to find a specific person to unblock — they have to scan the whole list instead of jumping to roughly where the name should be.

### Request

Please update the blocked contacts list so it's sorted alphabetically by the contact's displayed name (case-insensitive), the same way most other contact lists in the app already behave.

### Acceptance criteria

- Opening the blocked contacts screen shows entries in alphabetical order by display name.
- Blocking a new contact or unblocking an existing one while the screen is open updates the list and it stays correctly sorted (not just appended at the end).
- No other part of the app that happens to reuse this same code path should regress; if you touch shared code, double check who else calls it.

This should be a small, self-contained fix — no new screens or major feature work needed, just correct ordering.
