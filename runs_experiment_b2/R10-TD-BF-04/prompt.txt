Add a way for someone to delete every message they personally sent within a specific conversation, while leaving the other participant's (or participants', in a group) messages untouched. Think of it as a quick way to clean up "my side" of a conversation without wiping out the whole chat.

Requirements:

- The user can trigger this from within a conversation, and it removes only the messages authored by them in that conversation.
- If the user has other devices linked to their account, those messages should disappear there too — not just on the device where the action was performed. A deletion that only takes effect on one device isn't good enough.
- Immediately after the deletion, the conversation's preview text, unread state, and message list should reflect the change right away, without needing to relaunch the app.
- If any of the deleted messages correspond to a call that happened in that conversation, the call history should stay consistent with the deletion rather than showing a call entry that no longer has its associated message.

This should feel consistent with how other "delete" actions in the app already behave — the goal is a clean, complete removal, not a partial one that leaves stray state behind.
